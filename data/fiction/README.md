# data/fiction

Authored game content that makes no historical claim. Every file is `{"layer": "fiction", "records": [...]}` and every record carries `"provenance": {"status": "fictional"}`.

- `scenarios/`: where and when a game starts, which area it uses, the households and residents who live there (with their invented money: starting funds, rent, other income, wages, pantry), and which floor plan each building with an interior uses. Residents are fictional in every scenario.
- `schedules.json`: timetables with a weekday, a Saturday and a Sunday plan (wake, bed, work or school hours, fixed household mealtimes). Game design, not history.
- `interiors/floor_plans.json`: fictional floor plans, each made for a type and size of building. Interiors are never taken from the historical record (D-032).
