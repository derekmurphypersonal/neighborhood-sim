# data/fiction

Authored game content that makes no historical claim. Every file is `{"layer": "fiction", "records": [...]}` and every record carries `"provenance": {"status": "fictional"}`.

- `scenarios/`: where and when a game starts, which area it uses, and the households and residents who live there. Residents are fictional in every scenario.
- `schedules.json`: daily timetables (wake, bed, work or school hours). Game design, not history.
